Karwan plans to let a person connect their social accounts, so an agent can
find their Karwan record by handle. A buyer could ask their agent to check a
Telegram username and get back that person's tier, reasons and counts.

Connecting an account will be optional, in the agent workspace, and only with
the person's consent. Ownership is proven by signing in where the network
offers it, or by placing a code on the profile where it does not, so a link
alone never claims someone else's account. A linked handle is not proof of
identity.

This is not built yet. No network is a partner, and none is named as one.
