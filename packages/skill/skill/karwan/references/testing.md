# Full-loop testing

Test state, money, and identity as separate ledgers. A green UI or application log is not proof. Record actors, wallet map, amounts, timestamps, request IDs, receipts, decoded transfers, contract reads, database rows, screenshots, and notifications.

Cover external-wallet and email/Circle accounts, wrong chain, insufficient or stale balance, wrong signer, expired authorization, duplicate requests, webhook replay, RPC/database failure, process restart, reverted receipts, partial completion, and safe resume without replay.
